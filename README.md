# Python: учебные мини-проекты
Репозиторий с простыми учебными проектами на Python, написанными в процессе обучения.  
В проектах используются базовые конструкции: условия, циклы, ввод данных, работа со случайными числами.

## Проекты
### 1. Простой калькулятор (`simple_calculator.py`)
Консольный калькулятор: вводит два числа и операцию, выводит результат или сравнение чисел.
**Возможности:**
- Арифметические операции: `+`, `-`, `*`, `/`.
- Сравнение чисел: `>`, `<`, `==`.
**Что используется:**
- `if / elif / else` — выбор операции и сравнение чисел.
- `input()` — ввод данных.
- `float()` — работа с числами.
- `+ - * /` — арифметические операции.
**Как запустить:**
```bash
python calculator.py
```

### 2. Конвертер температуры (`temperature_converter.py`)
Простой конвертер: переводит температуру из Цельсия в Фаренгейт и обратно.
**Возможности:**
- Выбор направления: °C → °F или °F → °C.
- Использование формул перевода.
**Что используется:**
- `if / elif / else` — выбор направления конвертации.
- `input()` — ввод данных.
- `float()` — работа с числами.
- Формулы перевода между °C и °F.
**Как запустить:**
```bash
python converter_temperature.py
```

### 3. Игра «Угадай число» (`guess_number.py`)
Консольная игра: компьютер загадывает число от 1 до 20, пользователь пытается его угадать.
**Возможности:**
- Генерация случайного числа.
- Подсказки «больше» / «меньше».
- Подсчёт количества попыток.
**Что используется:**
- `if / elif / else` — сравнение чисел.
- `while` — повтор попыток.
- `input()` — ввод числа.
- `random.randint()` — генерация случайного числа.
**Как запустить:**
```bash
python guess_number.py
```

## Общая информация
- Язык: Python 3
- Формат: консольные приложения
- Уровень: учебные проекты для начинающих
